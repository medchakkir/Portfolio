# Mohamed Chakkir — Portfolio

Next.js 16 (App Router) + Tailwind CSS v4. Editorial design with light/dark themes and a case-study page per project.

## Develop

```bash
npm install
npm run dev     # http://localhost:3000
npm run lint
npm run build
```

## Editing content

- `data/content.ts` — hero, about, contact copy and links
- `data/projects.ts` — projects and case-study text (Problem / Approach / Outcome)
- `data/skills.ts` — skills lists
